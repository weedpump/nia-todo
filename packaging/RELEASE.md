# Public release packaging

This directory contains public-distribution overlays. The public repository is not copied from this directory directly; it is generated by `scripts/release/export-public.sh` from the private development tree plus these overlays.

## Release artifacts

A public release has exactly two distribution targets:

1. `nia-todo-server-vX.Y.Z-full.deb`
   - Debian/Ubuntu server installer
   - contains the web/server source
   - contains bundled Windows/Android client downloads under `/opt/nia-todo/web/downloads/`
2. Docker image
   - built from the same clean public export

Windows and Android installers/APKs are embedded into the server bundle, not published as separate required public assets.

## Scripts

```bash
scripts/release/export-public.sh X.Y.Z --output dist/public/nia-todo-X.Y.Z --init-git
scripts/release/build-full-bundle.sh X.Y.Z --windows-installer /path/app.exe --android-apk /path/app.apk
scripts/release/build-docker.sh X.Y.Z --tag nia-todo:X.Y.Z
scripts/release/public-release.sh X.Y.Z --windows-installer /path/app.exe --android-apk /path/app.apk
```

For local dry-runs without native app artifacts:

```bash
scripts/release/public-release.sh X.Y.Z --allow-missing-apps --skip-docker --force
```

## Public export rules

The export script intentionally uses tracked files and explicit exclusions. It overlays public-safe files from `packaging/` and fails if known private/dev markers are found.

Excluded examples:

- private Git history
- databases and runtime data
- generated build artifacts
- private/dev service files
- internal workflow docs
- test harness files with private paths

## Notes

The package currently installs Python dependencies during package installation via `pip`. For fully offline installation, add wheel vendoring later.
